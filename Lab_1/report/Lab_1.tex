The objective of the given experiment is to understand the concept of an artificial neuron and implement a Single Layer Perceptron from scratch for a binary classification task. 

%----------------------------------------------------------

\section*{2. Background Theory}

An Artificial Neuron is the fundamental building block of a neural network. It receives one or more input features multiplies with their corresponding weights and adds a bias term and also applies an activation function to determine the output.

The Single Layer Perceptron is the earliest supervised learning algorithm capable of solving linearly separable binary classification problems.

\subsection*{Mathematical Formulation}

Weighted Sum

\[
z=\mathbf{w}^{T}\mathbf{x}+b
\]

where

\begin{itemize}
\item $\mathbf{x}$ : Input vector
\item $\mathbf{w}$ : Weight vector
\item $b$ : Bias
\item $z$ : Linear combination
\end{itemize}

Prediction

\[
\hat y=f(z)
\]

Weight Update Rule

\[
\mathbf{w}_{new}
=
\mathbf{w}_{old}
+
\eta
(y-\hat y)
\mathbf{x}
\]

Bias Update

\[
b_{new}
=
b_{old}
+
\eta
(y-\hat y)
\]

where $\eta$ denotes the learning rate.

%----------------------------------------------------------

\section*{4. Activation Functions}

An activation function determines the output of a neuron based on the weighted sum of its inputs. It introduces non-linearity, enabling neural networks to learn complex patterns. Although the perceptron uses only the Step Activation Function, modern deep learning models employ differentiable activation functions for efficient optimization through backpropagation.

\subsection*{Step Activation Function}

\[
f(z)=
\begin{cases}
1,&z\ge0\\
0,&z<0
\end{cases}
\]

The Step Activation Function produces a binary output and is therefore suitable only for linearly separable binary classification problems.

\hline

\hline

Leaky ReLU & $(-\infty,\infty)$ & Avoiding Dying ReLU\\

\section*{12. Additional Tasks}

\subsection*{12.1 Step vs. Sigmoid Activation}

\begin{tabular}{|p{4cm}|p{5.5cm}|p{5.5cm}|}
\hline
\textbf{Property} & \textbf{Step} & \textbf{Sigmoid}\\
\hline
Output & Hard $\{0,1\}$ & Smooth $(0,1)$\\
\hline
Derivative & Zero everywhere, undefined at $z=0$ & Well-defined, non-zero almost everywhere\\
\hline
Gradient flow & None -- blocks backpropagation & Enables gradient-based learning\\
\hline
Confidence info & None (hard decision only) & Yes, output is a probability-like score\\
\hline
\end{tabular}

The Step function is not used in modern deep learning because it is non-differentiable and thus gradient descent and backpropagation cannot flow a useful error signal back through it. Sigmoid also has the advantage of giving a soft and interpretable output whereas Step only ever gives a hard class label.

\vspace{3mm}
\subsection*{12.2 Comparison with Scikit-learn's Perceptron}

Implementing \texttt{sklearn.linear\_model.Perceptron} with 50 iterations and 0.01 learning rate on the identical train/test split produced 97.09\% accuracy,93.85\% precision, 100\%recall and 96.83\%F1 scores that exactly matched the from scratch implementation .

\vspace{3mm}
\subsection*{12.3 Effect of Learning Rate}

The larger step sizes overshoot the decision boundary on data that is not perfectly linearly separable instead of settling into it.

\vspace{3mm}
\subsection*{12.4 Why a Single Layer Perceptron Cannot Solve XOR}

XOR is not linearly separable. Since a single-layer perceptron can only represent one linear decision boundary, it is mathematically incapable of solving XOR. 


\vspace{3mm}
\subsection*{12.5 Effect of Feature Normalization on Convergence}

Convergence speed and stability improve significantly with feature normalization. Since all features are brought to similar range, dominance is prevented by high magnitude features.

\vspace{3mm}
\subsection*{12.6 Perceptron Learning Algorithm for OR, NOT, and AND Gates}
The perceptron learning rule are implemented for the OR, AND, and NOT gates. Weights and bias were initialized to zero and were updated whenever a misclassification occurred. All these gates converged rapidly since their truth tables are linearly separable i.e OR converged in 5 updates, AND in 8 updates and NOT in 2 updates. The complete set of decision-boundary plots (EPS and PDF, 600 DPI) generated after each update is present in the Github:
\url{https://github.com/Srinidhi-Krishna/Deep-Learning-Lab/blob/main/Lab_1/gate_plots.zip}

\vspace{3mm}
\subsection*{12.7 Perceptron Learning Algorithm for the XOR Gate and Non-Convergence Analysis}
The perceptron learning rule are applied to the XOR gate. Unlike OR, AND, and NOT, the XOR truth table is not linearly separable as the positive class and the negative class lie on opposite diagonals of the input. So no single straight line can separate them. Each weight update corrects the currently misclassified point and also simultaneously breaks a previously correct one . This confirms the result that a single layer perceptron cannot represent non-linearly-separable functions such as XOR and can only be fixed by introducing a hidden layer. The decision-boundary plots after every update and the Training Error vs Epoch plot is present in the Github:
\url{https://github.com/Srinidhi-Krishna/Deep-Learning-Lab/blob/main/Lab_1/xor_plots.zip}

\section*{13. Discussion}

The from-scratch implemented perceptron performs well with a test accuracy of  97.09\% on the Banknote Authentication dataset. This shows that the classes are almost, but not fully, linearly separable. Although the model had misclassifications, it never allowed a forged note to pass through. Overall the model performed excellently.

%----------------------------------------------------------

\section*{14. Conclusion}

This experiment therefore successfully demonstrates a Single Layer Perceptron. While the model is highly efficient for datasets that are approximately linearly separable by achieving over 97\% accuracy it fails while dealing with highly overlapping data. Thus transition to multilayer networks and differentiable activation functions is necessary to deal with more complex and non-linear challenges.
